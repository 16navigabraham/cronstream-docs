# Cronstream Protocol

Cronstream is a Uniswap v4 hook that restores the native yield distribution pipeline for Real-World Asset (RWA) and rebasing stablecoin pools. When yield-bearing assets like USDY, USDM, or BUIDL enter a standard AMM pool, their dividend and rebase mechanisms break. Cronstream intercepts that stagnant yield and pushes it directly to liquidity providers' wallets — atomically, without custody, and with zero protocol fee.

<Callout type="info">
  Cronstream is currently in active development as part of the Uniswap Hook Incubator (UHI) cohort. Testnet deployment is scheduled post-cohort.
</Callout>

## The capital displacement problem

The tokenized RWA market has crossed **$31.4 billion** in on-chain value, anchored by **$13.53 billion** in tokenized U.S. Treasuries. Institutional vehicles have moved aggressively onto public networks:

| Asset | Issuer | AUM |
|---|---|---|
| BUIDL | BlackRock | $2.4B |
| USDY | Ondo Finance | $2.16B |
| USDM | Mountain Protocol | $1.1B |

These assets generate real yield — Treasury dividends, stablecoin rebases, lending rate accrual. But the moment they are deployed into a Uniswap pool to build secondary market liquidity, that yield distribution mechanism breaks entirely. The Uniswap v4 `PoolManager` singleton has no awareness of external token rebases or dividend accrual schedules. Yield accumulates as idle, unassigned float inside the pool manager, collecting 0% compound velocity.

The only current recovery path is a manual off-chain operation: snapshot the LP registry, calculate pro-rata shares, and execute a batch transfer via a centralized multi-sig. This introduces custody risk, human-error liability, and a compliance classification problem — regulators in both the US and EU have begun treating manual yield distribution operations as evidence of a centralized clearinghouse structure.

## What Cronstream does

Cronstream attaches to a Uniswap v4 pool as a hook contract. It:

1. Tracks each LP's liquidity weight as positions are opened and closed
2. Detects yield surplus from token rebases and swap fee accumulation
3. Waits for an off-chain keeper to trigger distribution when a capital threshold is crossed
4. Executes an atomic flash-accounting transaction that pulls the surplus, reimburses the keeper's gas inline via an exact-output swap, and pushes the remaining yield directly to every LP's wallet

The hook charges no protocol fee. 100% of yield flows to LPs. The keeper is reimbursed entirely from the yield pool in the same block as distribution, creating a self-sustaining execution model.

## Core design invariants

| Invariant | Specification |
|---|---|
| Zero custody | Hook never holds principal LP funds. All liquidity stays inside the `PoolManager` singleton |
| Gas invariance | Keeper wallet is fully reimbursed in native ETH within the same transaction block |
| Permissionless trigger | `distributeYield()` is a public entrypoint — no `onlyOwner`, no access control |
| Zero protocol fee | 0% taken on distributed yield. Protocol is funded through ecosystem grants, not value extraction |
| Cancun-native | Deployed on Cancun-active networks (Base, Arbitrum, Unichain). EIP-1153 transient storage used throughout |

## Who this is built for

Cronstream is infrastructure for asset issuers, institutional LPs, and protocol treasuries deploying yield-bearing assets on Uniswap v4. It is not a consumer product. The design target is a corporate treasury allocating $10M+ in tokenized Treasuries to a Uniswap pool — a use case that currently has no automated, non-custodial yield distribution solution.
