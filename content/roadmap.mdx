# Roadmap

Cronstream is in active development. The roadmap is sequenced around the three hard constraints that matter for institutional infrastructure: correct implementation, external verification, and mainnet deployment with real TVL.

## Phase 1 — Core implementation (UHI Cohort)

Active development phase. All work targets a local Foundry environment against forked mainnet state.

| Milestone | Description | Status |
|---|---|---|
| Hook scaffolding | `CronstreamHook.sol` inheriting `BaseHook.sol`, correct permission flags | In progress |
| LP ownership matrix | `afterAddLiquidity` / `afterRemoveLiquidity` tracking with persistent storage | In progress |
| Transient storage library | `TransientAccounting.sol` Yul assembly wrappers for EIP-1153 slots | In progress |
| Flash accounting | `distributeYield()` → `unlockCallback()` lock-callback state machine | In progress |
| Inline gas reimbursement | Exact-output ETH swap + `tx.origin` transfer within unlock session | In progress |
| Foundry test suite | Mock RWA rebase tokens, keeper simulation, pro-rata distribution assertions | In progress |
| Keeper script | TypeScript automation against live RPC — threshold monitoring and tx broadcast | In progress |
| Hookathon submission | UHI Demo Day — live Foundry terminal execution against forked mainnet | Target: cohort end |

## Phase 2 — Testnet deployment

Post-cohort. Targets all three Cronstream deployment networks simultaneously.

| Milestone | Description |
|---|---|
| Base Sepolia deployment | Hook deployed against Uniswap v4 on Base Sepolia |
| Arbitrum Sepolia deployment | Hook deployed against Uniswap v4 on Arbitrum Sepolia |
| Unichain testnet deployment | Hook deployed on Unichain testnet |
| Mock RWA pool | USDY/USDC testnet pool with simulated rebase events |
| Keeper network | Public keeper infrastructure — anyone can run a keeper node |
| Public testnet dashboard | Pool state, accumulated yield, distribution history |

## Phase 3 — External security audit

No mainnet deployment without a completed external audit. This is a non-negotiable constraint for institutional TVL.

Target audit scope:
- Flash accounting and delta settlement correctness
- Reentrancy attack vectors via transient storage
- LP ownership matrix manipulation during distribution
- Inline swap MEV exposure during keeper reimbursement
- Edge cases: zero LP count, single LP, pool with no registered surplus

<Callout type="warning">
  Cronstream will not pursue TVL or mainnet deployment until an audit report is published. Unaudited hooks are unsuitable for institutional capital regardless of correctness claims.
</Callout>

| Milestone | Description |

| Keeper network expansion | Third-party keeper operators onboarded |
| Uniswap Foundation grant application | Formal grant application with live TVL data |

## Phase 5 — Asset issuer integrations

Long-term track. Direct integration partnerships with RWA asset issuers to make Cronstream the default yield distribution layer for their Uniswap pools.

Each integration gives the issuer:
- Automated yield distribution to LPs without manual operations
- Non-custodial settlement architecture satisfying compliance requirements
- LP acquisition advantage vs. pools without automated distribution

Target issuers: Ondo Finance (USDY), Mountain Protocol (USDM), BlackRock (BUIDL), Franklin Templeton (BENJI), Superstate (USTB).
